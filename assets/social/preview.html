transport-io
Real-time apps over WebTransport. Two lanes, one contract, no fallback.
contract.ts
const contract = defineContract({
  chat:   reliable<{ from: string; body: string }>(),
  cursor: unreliable<{ x: number; y: number }>(),
  ask:    streaming<{ prompt: string }, string>(),
})
client.ts
client.emit('chat', { from, body })  // arrives
client.emit('cursor', { x, y })      // may not

for await (const t of client.stream('ask', { prompt })) {
  render(t)                          // break = reset
}
QUIC streams for what must arrive. Datagrams for what may not. Chrome, Firefox. Node 22.
