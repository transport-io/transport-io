RULES
  The mark is monochrome. Ink on light grounds, bone on dark. The accent
  (#C2551D) never appears inside the mark.
  No outline, no stroke, no shadow, no rounding, no gradient.
  Clear space: half the slab width on every side.
  Minimum size: 16 px. Below that use the slab alone, without the wedge.
  Do not recolour, rotate, skew, or reseat the wedge.

LOCKUP TYPE
  The lockup sets the wordmark as live text in IBM Plex Mono SemiBold. If it
  will be used where that font is not installed, convert the text to outlines
  in a vector editor first.

AVATARS (derived, not part of the original delivery)
  avatar/org-avatar-ink-ground-512.png    bone mark on an ink tile
  avatar/org-avatar-bone-ground-512.png   ink mark on a bone tile

  The delivered PNGs have transparent backgrounds, so on GitHub the ink mark
  disappears against a dark theme and the bone mark disappears against a light
  one. An avatar needs its ground baked in, which is what these are. Generated
  from the 512 px marks with the mark at 56% of the tile, which keeps more than
  the half-slab clear space the rules require.

  Prefer the ink ground. It is bold on a light page, and on a dark page the
  tile edge recedes while the mark still reads.
